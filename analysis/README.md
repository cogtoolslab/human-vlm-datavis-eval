Directory to contain analysis notebooks/scripts for this project.

## Files:
- - `response_processing/*`: Used to find proportion of valid responses generated by each model on each test using only adapted prompts and to generate Figure 1B
- `create_test_by_valid_responses_across_models.py`: Used to find proportion of non-empty responses produced by each model on each test using both raw and adapted prompts and to generate Figure 4
- `create_model_by_accuracy_invalid-included.py`: Used to generate Figure 5A. Mean proportion correct on multiple-choice assessments. Empty circles represent estimates of model performance based on all responses, with any invalid responses marked as incorrect. Filled circles represent estimates of model performance based only on valid responses, and therefore reflect an upper bound on model performance. 
- `create_model_by_accuracy.py`: Used to find human and model performance on each test and generate Figure 5B and 9. Each dot represents an individual item. Estimates of average model performance only include valid responses and therefore reflect an upper bound on model performance.
- `create_model_by_accuracy_across_graphtype.py`: Used to create accuracy plot for each graph type shown in Figure 6
- `create_model_correlation_heatmap.py`: Used to create Figure 7A. Error similarity matrix indicating the Pearson correlation between error patterns generated by every pairwise combination of vision-language models and Humans on items from GGR, VLAT, & CALVI. An error pattern is defined as a vector with length equal to the number of items, where the value of each element is the proportion of correct responses given for a single item, across all repeated administrations of that item.
- `create_human_model_correlation_by_model.py`: Used to create Figure 7B. Pearson correlation between error patterns produced by each model and Humans on the same assessments. Error bars represent 95% confidence intervals constructed using the Fisher transformation. Each dot represents model-human consistency for a single assessment. Human noise ceiling estimated by computing Spearman-Brown-corrected correlation between split-halves of the human data.



- `statistical_contrasts.ipynb`: Used to find statistical contrasts (difference of means) and confidence intervals in the subsection for pairwise comparisons between models and humans (subsection "How similar were responses generated by models and humans").
- `environment.yml` specifies a conda environment with the appropriate packages to reproduce our code. We recommend creating a new conda environment using the following command:
   ```
   conda env create -f environment.yml
   ```
